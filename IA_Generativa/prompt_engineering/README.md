# BarraFácil - Sistema de Gestión para Cafetería Local

## 1. Prompt de Google Stitch (Interfaz Visual)

### Prompt inicial para el diseño de la interfaz:
```
Design a warm, highly functional web dashboard UI for a local neighborhood coffee shop management system named "BarraFácil".
COLOR PALETTE (STRICTLY APPLY THESE EXACT CODES):
- Primary Dark / Text / Header: Dark Roasted Coffee Brown (#4A2E2B)
- Accent / Primary Buttons / Highlights: Warm Caramel (#C68B59)
- Secondary / Card Borders: Medium Coffee Accent (#8B5E3C)
- Background Base: Light Cream / Off-white (#F7F0E6)
- Subtle Backgrounds / Hover States: Muted Mocha Beige (#DDB8A2)
LAYOUT & STRUCTURE:
1. Top Navigation Bar: Warm Dark Brown (#4A2E2B) background with cream text. Features the logo "BarraFácil | Control de Local" and a 3-tab navigation bar: [1. Pedidos / Comandas, 2. Inventario, 3. Cuentas y Caja].
2. Main Content Area (Split into 2 Bootstrap-style columns):
   - Left Column (Input Form / 4 cols wide): Styled form card with a cream background, caramel action button, and medium brown input borders. Includes fields for Order Registration (Item name, Table number, Quantity, Notes).
   - Right Column (Active Orders Grid / 8 cols wide): Cards displaying active coffee shop orders (e.g., "Tinto x2 - Mesa 3", "Perico + Pandebono"). Each card features a top accent line in Warm Caramel (#C68B59), clear text hierarchy, and a status toggle button.
3. Visual Polish: Soft hover elevation on cards, crisp typography, clean semantic UI boundaries, and an inviting, artisanal local coffee shop atmosphere.
```

### Prompt de ajuste posterior:
```
Realiza las paginas para Inventario, Cuentas y Cajas y Pedidos/Comandos
```
